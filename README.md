## المزايا

- تنظيم أعمال الصيانة الوقائية (PM) والفحص الدوري (Routine check).
- لصق رسائل متعددة، واستخراج بيانات الأعمال، ومعاينتها ومراجعتها قبل الاعتماد.
- دعم أعداد الأجهزة ونوع النظام وبيانات فريق العمل، وربط تقارير الورديات مع طلب المراجعة عند الالتباس.
- تصدير CSV يتضمن حالة الإنجاز.

## التثبيت

1. استخدم جهازًا يعمل بنظام Android 7.0 أو أحدث.
2. نزّل APK من صفحة الإصدار وافتحه، واسمح بالتثبيت من التطبيق المستخدم للتنزيل عند طلب النظام.
3. راجع البيانات المستوردة قبل اعتمادها، وأكمل بيانات الفريق الناقصة.

هذه نسخة تطوير قابلة للتصحيح وموقعة بمفتاح Android Debug، وليست إصدار متجر أو إصدار إنتاج. قد يتعذر تحديث تثبيت سابق إذا اختلف التوقيع؛ احتفظ بنسخة من بياناتك قبل أي إزالة للتطبيق.
