## اختيار المصدر

من الإعدادات اختر الإشعارات أو الشيت. يعمل مصدر واحد تلقائيًا، وتبقى السجلات السابقة محفوظة دون دمج تلقائي بين المصدرين.

للشيت: الصق رابط ملف Google Sheets أو المجلد المشارك واضغط «حفظ الرابط وتحديث». يلزم أن يُفتح الرابط للمشاهدة دون تسجيل دخول Google، مع السماح بقراءة CSV. يقرأ التطبيق قالب صفحة Report، ويُعيد قراءة الأيام القديمة لالتقاط التقارير المتأخرة. اكتشاف ملفات المجلدات الفرعية تجريبي وقد لا يُظهر جميع الملفات؛ رابط الشيت المباشر أدق. لا يدعم ملفات Excel أو الملفات المقيدة بحساب.

للإشعارات: فعّل الوصول للإشعارات وحدد تطبيق المصدر ثم اختر القروب المكتشف. يُقرأ تعليق الصورة عندما يكشفه أندرويد؛ الصور بلا نص لا تُحسب عملًا. لا يستورد التطبيق سجل واتساب ولا يقرأ الصور نفسها.

يتوفر AI محلي تجريبي اختياري، مع تجربة استخراج دون حفظ. النموذج الصغير مضمّن ومعطّل افتراضيًا، ولا يرسل رسائلك لخدمة ذكاء اصطناعي. يبقى التعديل اليدوي اختياريًا، ولا يوجد تبويب مراجعة أو اعتماد.
